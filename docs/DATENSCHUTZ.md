# Datenschutzerklärung

Stand: 27.11.2026 · gilt für Glimra OS, die GlimraApp (Android) und den Glimra Setup-Manager (Windows).

## Kurz gesagt

Glimra OS sammelt **keine** Daten über dich. Es gibt keine Telemetrie, keine Werbung, keine Konten bei uns und keine Server von uns.

## GlimraApp (Android)

- Die App verbindet sich **nur mit Geräten in deinem eigenen Netzwerk**, die du selbst koppelst.
- Gespeichert werden nur auf deinem Handy: IP-Adresse, Name und Schlüssel der gekoppelten Geräte.
- Daten, die du sendest (Zwischenablage, Dateien, Nachrichten, Links), gehen direkt an deinen PC – nicht ins Internet.
- Berechtigungen: Internet/WLAN (für die Verbindung im Heimnetz), Multicast (um PCs im WLAN zu finden).
- Beim Deinstallieren werden alle gespeicherten Daten gelöscht.

## Glimra Setup-Manager (Windows)

- Lädt auf deinen Wunsch die Glimra-OS-ISO von GitHub und Rufus von GitHub herunter (dabei gelten die Datenschutzregeln von GitHub).
- Deine Dateien werden nur dorthin kopiert, wohin du sie schickst (USB-Stick, Ordner oder dein Glimra-OS-PC im Heimnetz).

## Glimra OS

Verbindungen ins Internet entstehen nur durch Funktionen, die du nutzt:

| Funktion | Ziel |
|---|---|
| Updates und Programme installieren | Arch-Linux-Paketserver (Mirrors), bei Flatpak: Flathub |
| Virendatenbank aktualisieren | ClamAV-Datenbankserver |
| Sprachassistent einrichten | alphacephei.com (einmaliger Download des Sprachmodells) |
| Browser, Steam, E-Mail | die jeweiligen Anbieter |

Die Spracherkennung läuft vollständig auf deinem PC.
