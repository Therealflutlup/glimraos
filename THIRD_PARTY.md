| Software | Verwendung | Lizenz |
|---|---|---|
| Arch Linux Pakete (Kernel, systemd, pacman, archiso …) | Unterbau der ISO | jeweilige Paketlizenzen |
| Qt 6 / PySide6 | Glimra Shell | LGPL-3.0 |
| QEMU/KVM, libvirt | Virtuelle PCs (optional) | GPL-2.0 / LGPL-2.1 |
| ClamAV, ufw | Sicherheit | GPL-2.0 / GPL-3.0 |
| Vosk + vosk-model-small-de | Spracherkennung (optional, wird bei Bedarf geladen) | Apache-2.0 |
| gamescope, Wine, Steam | Spiele (optional, Gaming-Profil) | BSD-2 / LGPL-2.1 / proprietär (Valve) |
| Rufus | USB-Stick (wird vom Setup-Manager bei Bedarf geladen) | GPL-3.0 |
| PyInstaller | baut GlimraSetup.exe | GPL-2.0 mit Ausnahme |

„Arch Linux“ ist eine Marke der Arch-Linux-Projektverantwortlichen. Glimra OS ist kein offizielles Arch-Projekt.
